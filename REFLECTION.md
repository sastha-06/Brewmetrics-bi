# Reflection

Working on the BrewMetrics project with GitHub Copilot changed how I approached a Power BI project. Copilot was useful when creating the DAX measures because it gave me a starting point for Total Sales, Previous Month Sales, MoM Sales Growth %, Running Total Sales, and City Sales Rank. It also helped me understand how the measures worked with the date and city dimensions. However, I learned that Copilot suggestions should not be accepted without checking them. I reviewed and tested the measures in Power BI and checked details such as month ordering and percentage formatting before using them in the report.

The biggest difference from a normal single-file Power BI lab was using Git and making incremental commits. Instead of completing everything in one file and saving it at the end, I committed the star schema, each DAX measure, Copilot notes, and dashboard separately. This gave me a clear history of how the project developed and made individual changes easier to identify.

Using Copilot made the DAX development faster, but I still had to understand and test the suggestions myself. Using Git also made me more organised because I could track each stage of the project. Overall, the combination of Copilot, Power BI, and Git gave me a more structured workflow.
